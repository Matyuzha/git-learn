# Git learning

## Шаг 1. Проверь, привязан ли удаленный репозиторий

Выполни:

    git remote -v

Если ничего не вывелось (или адрес ведет куда-то не туда), привяжи свой новый репозиторий:
    
    git remote add origin git@github.com:Matyuzha/имя_репозитория.git

(Замени имя_репозитория на реальное название того, что ты создал на GitHub).

## Шаг 2. Добавь файлы и сделай коммит (если еще не сделал)

Убедись, что все нужные файлы добавлены в индекс и зафиксированы:

    git add .
    git commit -m "initial commit"

(Если терминал пишет nothing to commit, working tree clean — значит, файлы уже закомичены, и этот шаг можно пропустить).
## Шаг 3. Отправь код на GitHub

Запушь ветку master на удаленный сервер:
    
    git push -u origin master

Всё! После этого файлы появятся на странице репозитория в браузере. В дальнейшем для отправки обновлений будет достаточно писать просто git push.
